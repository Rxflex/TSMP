The Sims 4 multiplayer for two

Play The Sims 4 with a friend. Two people share one world, on one local network or over the internet, and the launcher does the setup: it finds the other computer, copies the mods and the save, and starts both games with the packs both players own.

How to play The Sims 4 with a friend

You need two Windows computers, each with its own copy of The Sims 4 at the same version, and script mods enabled in the game options. On one local network that is all; from different networks you also need a session server.

  1. Both download tsmp.exe

    One file, with the mod inside. Run it on both computers. Windows asks once to allow it through the firewall: allow it on private networks, or the host will not be found.

  2. One of you hosts

    Choose Host a session and pick the save to share. Your save and your mods become the shared ones; the launcher puts the mod into your Mods folder.

  3. The other joins

    Choose Join a session, pick the host from the list, read what will change and press Sync. Then both press Start game and load the shared save.

The guest loads the host's world once more after its lot loads; the host's game stays paused until the launcher says Live. Both games are joined. Keep the launcher open while playing: it carries the session.

Only join people you trust. Joining runs the host's script mods on your computer, and script mods are unrestricted code.

  • Files the host lacks, and local versions that differ, are moved to Mods.tsmp-backup/<date>/ next to the Mods folder. Saves go to saves.tsmp-backup/ the same way.
  • The game from the EA app and from Steam both work. A Steam copy is started through Steam, which may ask to confirm the launch arguments.
  • After the game starts, the launcher warns if it loaded packs the session should not have.
  • The launcher speaks Deutsch, English, Español, Français, Italiano, Polski, Português (Brasil), Русский, Українська and 简体中文.

Playing over the internet

Two computers on different networks usually cannot reach each other, so they meet on a TSMP session server that both can reach: one that a friend runs, or your own.

  1. The host opens the session as usual. Under Over the internet on the session screen they enter the server's address and press Open. The launcher shows an invite such as K7QM-2XDA@play.example.org.
  2. The host sends the invite to the other player.
  3. The other player chooses Join a session, pastes the invite where the host's address goes and presses Connect. From here everything is as on a local network.

The invite stays the same if the host's connection drops for a moment. So far only in tests

Running a session server

tsmp-server is one small file for Linux, without settings files, that keeps nothing on disk. Any computer both players can reach will do, typically a cheap Linux server with a public address. It needs one TCP port open, 47810 by default. It only passes bytes between the two launchers, so its connection decides how fast the guest syncs.

Take tsmp-server-linux-x86_64 from the latest release (it runs on any x86_64 Linux), or build it with cargo build --release -p tsmp-server. Then:

chmod +x tsmp-server-linux-x86_64
./tsmp-server-linux-x86_64 --listen 0.0.0.0:47810

A session code is eight characters, and an address that keeps asking for codes that do not exist is held back, so codes cannot be found by guessing. Anyone who has an invite can join that session: send it only to the person you are playing with. The README has a systemd unit and the limits --help lists.

Each with their own family

Each player can bring a household from a save of their own. The host picks Each with their own family when they start hosting, and then no save is copied; each player loads their own save.

When the guest comes to the host's lot, its household, with its sims, home lot and relationships, is copied into the host's save, and the guest goes on playing it there. Both launchers back up their saves first, because each game may write the other's family into its own.

So far only in tests

Questions and answers

Is there official multiplayer in The Sims 4?

No. The game has no multiplayer of its own. TSMP is a fan project that adds it with a script mod and a launcher. It is not affiliated with or endorsed by Electronic Arts.

How do I play The Sims 4 with a friend?

Both players run tsmp.exe. One chooses Host a session and picks a save, the other chooses Join a session, picks the host and presses Sync, and both press Start game in the launcher and load the shared save. On one local network the host is found by itself; from different networks the host sends an invite through a session server. See How to play and Playing over the internet.

Is TSMP free?

Yes. It is open source under the MIT licence. There is no paid version and no early-access tier.

Does each player need their own copy of the game?

Yes. Each player needs their own Windows computer with their own copy of The Sims 4, at the same game version. The launcher warns when the two versions differ. The base game is free on the EA app and Steam.

How many people can play?

Two: one host and one guest.

Do we need the same packs (DLC)?

No. Players with different packs play with the packs they have in common: the launcher starts both games with the game's own -disablepacks: option and warns if a game loaded packs the session should not have. TSMP does not unlock content you do not own.

What about mods and custom content (CC)?

The host's Mods folder is the shared one. When the guest presses Sync, their Mods folder is made the same as the host's, CC included, and they see what will change first. Nothing is deleted: files the host lacks, and local versions that differ, are moved to Mods.tsmp-backup/<date>/ next to the Mods folder. Script mods must be allowed in the game options on both computers.

Can I use TSMP together with S4MP or another multiplayer mod?

No. They patch the same parts of the game. When you start hosting, the launcher moves the S4MP files it finds out of the Mods folder into the backup folder; nothing is deleted. Remove any other multiplayer mod first.

Do I have to install the mod myself?

No. The mod is built into tsmp.exe. The launcher puts it into the host's Mods folder when hosting starts, and the guest receives it with the sync.

What happens to my saves?

When you play one family together, the host's save is copied to the guest, and the guest's saves that would be replaced go to saves.tsmp-backup/ first. In Each with their own family no save is copied, and both launchers back up their saves before the session, because each game may write the other's family into its own.

Can we play over the internet, not only on one network?

Yes, through a TSMP session server that both players can reach: one a friend runs, or your own (tsmp-server, a small Linux program that needs one TCP port, 47810 by default). The host gets an invite such as K7QM-2XDA@play.example.org and sends it to the other player. This part is new and so far has been tried only against the game's protocol in tests.

Can each of us play our own family?

Yes. With Each with their own family, the guest brings a household from a save of their own, with its relationships, into the host's world and keeps playing it there. This is new and so far tried only in tests.

Can we build a house together?

Yes, on a game version whose addresses are in the repository (now 1.129.39.1030); the launcher's home screen says whether building together is ready for yours. In build mode, walls, floors and wall coverings drawn by either player appear for the other while both keep building. This was tried on two computers. Furniture and household funds in build mode have not yet been checked for double counting, and an element both edit at the same moment may end up different in the two games.

What has actually been tested?

Tried with two computers and two copies of the game: live mode, building together, different packs and the one-button setup on a local network. So far only in tests against the game's protocol: playing over the internet, families of their own, Create-a-Sim for the guest and different lots. The project is experimental; reports from your games are welcome.

Does it work on Mac, Linux or consoles?

No. The launcher and the mod are for The Sims 4 on Windows only. Only the optional session server runs on Linux.

Does it work with Steam and the EA app?

Yes. The launcher finds the game installed by either. A Steam copy is started through Steam, which may ask you to confirm the launch arguments.

Is it safe? Windows or my antivirus warns about it.

The code is open, and every release lists the SHA‑256 checksums of its files. The release files are not code-signed, so Windows may warn the first time; you can also build everything from source. Windows asks once to allow tsmp.exe through the firewall: allow it on private networks, or the host will not be found.

Joining runs the host's script mods on your computer, and script mods are unrestricted code. Only join people you trust.

Will a game update break it?

It can. Building together depends on addresses inside the game that change between builds. The mod checks the build before it touches anything: on a build it does not know, build mode sync switches itself off and the rest keeps working. Once the addresses for a new version are added to the repository, the launcher downloads them by itself, and it updates itself from the project's GitHub releases. Set the environment variable TSMP_NO_UPDATE to switch the self-update off.

Which languages does the launcher have?

Deutsch, English, Español, Français, Italiano, Polski, Português (Brasil), Русский, Українська and 简体中文. Most translations have not yet been checked by native speakers; corrections are welcome.
